# Tickets Analysis Dashboard - Power BI

An interactive Power BI dashboard providing insights into customer support tickets — trends, response performance, resolution rates, and agent efficiency.

---

##  Project Overview
This dashboard helps visualize and analyze key metrics related to support ticket handling:
- Ticket volume trends over time
- Average resolution and response times
- Agent and team performance comparisons
- Customer satisfaction and ticket backlog tracking
- Key influencers to improving perfromance

---

There are **6 pages** in total, covering detailed analysis by teams, region, and category.
## Tools & Techniques
- **Power BI Desktop**
- **Power Query** for data cleaning
- **DAX** for calculated metrics
- **Excel/CSV** as data source
